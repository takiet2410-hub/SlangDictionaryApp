GỢI Ý KHI CODE LOADER
------------------------------------------------------------
1. Bỏ qua dòng 1 (header).
2. Với mỗi dòng: nếu không chứa ` thì ghi log + bỏ qua (hoặc gán vào key của dòng liền trước theo A2).
3. trim() cả key lẫn từng definition; split meaning bằng "\\|" rồi trim từng phần.
4. Dùng Map<String, List<String>> (ví dụ HashMap/TreeMap) để 1 key giữ được nhiều definition
   (HB, HH, OTW, AMA...). Tránh List thuần vì đề trừ còn tối đa 70đ.
5. Đọc file bằng UTF-8 tường minh (StandardCharsets.UTF_8) để không vỡ ký tự ở dòng 7661-7662.
